# الوقف الرقمي (Digital Waqf) - دليل النشر والاستضافة المجانية
### صدقة جارية عن روح الفقيد: تاج الدين مزيود (رحمه الله وأسكنه فسيح جناته)

تم تحويل هذا الموقع بالكامل من PHP + MySQL إلى موقع ثابت فائق الخفة والسرعة (Static Site: HTML5 / CSS3 / Vanilla JS ES Modules) مهيأ للنشر المجاني مدى الحياة بنسبة 100% وبدون أي تكاليف استضافة على منصة **Vercel**.

---

## 🌟 مميزات النسخة الثابتة الجديدة
1. **استضافة مجانية 100% على Vercel**: بدون الحاجة لسيرفر PHP أو قواعد بيانات MySQL مكلفة.
2. **القرآن الكريم كاملاً (114 سورة محلياً)**: بيانات السور مقسمة في ملفات JSON مستقلة بالرسم العثماني الدقيق (مجمع الملك فهد / تنزيل) مع الترجمة الإنجليزية (Sahih International) ودعم العمل دون اتصال بالإنترنت.
3. **تلاوة صوتية خاشعة (EveryAyah CDN)**: مشغل صوتي متكامل بثلاثة قراء (مشاري العفاسي، محمود خليل الحصري، عبد الباسط عبد الصمد) مع التبديل التلقائي للآيات وتظليل الآية الحالية.
4. **محرك بحث ذكي**: يدعم تطبيع الحروف العربية وتجاهل علامات التشكيل وتوحيد الهمزات والألف، دون المساس بالنص القرآني المعروض.
5. **مسبحة رقمية وأذكار وأدعية**: عداد تسبيح تفاعلي بالصوت والاهتزاز وحفظ الإحصائيات في `localStorage`.
6. **معرض صور ميموريال WebP**: تحويل الصور لصيغة WebP الحديثة فائقة السرعة مع عارض Lightbox متقدم.
7. **الوضع الداكن والفاتح**: دعم كامل لـ Dark Mode والتبديل اللغوي الفوري (عربي / إنجليزي) بدون إعادة تحميل الصفحة.
8. **توافق كامل مع معايير الوصول (WCAG AAA)**: تباين ألوان معتمد، تنقل كامل بلوحة المفاتيح، ودعم `prefers-reduced-motion`.

## 🚀 دليل النشر على Vercel خطوة بخطوة

### الخطوة 1: التجربة المحلية (Local Testing)
للتأكد من عمل الموقع محلياً على جهازك قبل رفعه، افتح نافذة الأوامر (Terminal / PowerShell) داخل مجلد `static-version` ونفذ أحد الأمرين:

```bash
# باستخدام Python:
python -m http.server 3000

# أو باستخدام Node.js:
npx serve .
```
ثم افتح متصفحك على الرابط: `http://localhost:3000`.

---

### الخطوة 2: رفع المشروع على GitHub

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في [GitHub](https://github.com/) باسم مثلاً `sadaqa-jariya`.
2. في مجلد المشروع، نفذ الأوامر التالية لرفع مجلد `static-version`:

```bash
# تهيئة مستودع Git
git init

# إضافة الملفات
git add .

# تسجيل الـ Commit
git commit -m "Initial commit: Static Digital Waqf platform for Tadjeddine Mezioud"

# ربط المستودع بـ GitHub (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/YOUR_USERNAME/sadaqa-jariya.git

# دفع الكود
git branch -M main
git push -u origin main
```

---

### الخطوة 3: الربط والنشر على Vercel (مجاناً)

1. توجه إلى موقع [Vercel](https://vercel.com/) وسجل الدخول بحساب GitHub الخاص بك.
2. اضغط على زر **"Add New..."** ثم اختر **"Project"**.
3. ستظهر لك قائمة بمستودعاتك على GitHub، اضغط **"Import"** بجانب مستودع `sadaqa-jariya`.
4. في شاشة الإعدادات:
   - **Root Directory**: اضغط على "Edit" واختر مجلد `static-version` (إذا قمت برفع المشروع كاملاً).
   - **Framework Preset**: اتركه **Other**.
   - **Build and Output Settings**: لا تحتاج لتغيير أي شيء.
5. اضغط على زر **"Deploy"**.
6. في غضون ثوانٍ معدودة، سيكون موقعك حياً على الإنترنت برابط رسمي سريع ومجاني (مثال: `https://sadaqa-jariya.vercel.app`) مع شهادة أمان SSL مجانية ومدى الحياة!

---

### الخطوة 4: ربط نطاق مخصص (Custom Domain) - اختياري

إذا كان لديك نطاق خاص (Domain مثل `waqf-tadjeddine.com`):
1. داخل لوحة تحكم مشروعك في Vercel، اذهب إلى تبويب **Settings** -> **Domains**.
2. أضف النطاق الخاص بك واضغط **Add**.
3. سيعطيك Vercel سجلات DNS (A Record أو CNAME) لإضافتها في لوحة تحكم مزود النطاق لديك (مثل Namecheap أو Cloudflare).
4. بمجرد إضافتها، سيقوم Vercel تلقائياً بتفعيل شهادة التشفير HTTPS مجاناً.
